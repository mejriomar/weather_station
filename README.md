# Weather Station Project

## Overview
The Weather Station project aims to provide real-time weather data monitoring through various hardware components combined with software development. 

## Features  
- Real-time weather data collection  
- User-friendly dashboard for data visualization  
- Support for multiple hardware platforms  
  
## Project Structure  
The project consists of three main directories:  
1. **espwroom32**: Contains code for the ESP32 microcontroller for data collection.  
2. **stm32f411e**: Contains code for the STM32F411 microcontroller for advanced processing.  
3. **weather_station_dashboard**: Provides a web-based interface to visualize weather data.  
  
## Hardware Components  
- ESP32 microcontroller  
- STM32F411 microcontroller  
- Various sensors for temperature, humidity, and atmospheric pressure  
- Power supply and circuit components  
  
## Getting Started  
To get started with the Weather Station project, follow these steps:  
1. Clone the repository:  
   ```bash  
   git clone https://github.com/mejriomar/weather_station.git  
   ```  
2. Navigate to the desired directory for your hardware platform.  
3. Open the project files in your IDE and make necessary configurations.  
  
## Installation Instructions  
- Install the required libraries for your microcontroller.  
- Follow the instructions provided in each section to upload the code to your specific hardware.  
- Ensure that all components are connected properly before powering on.
